## 📖 Overview

The **Employee Payroll Management System (EPMS)** is a web-based application developed for **PayMaster Ltd**, a transportation and logistics company located in Rubavu District, Rwanda.

The system was designed to replace the company's manual payroll processing system, which was slow, error-prone, and difficult to maintain. EPMS automates employee management, payroll calculation, salary processing, and report generation, improving efficiency and accuracy within the Human Resource Department.

## 🔄 System Workflow

1. HR Officer logs into the system.
2. Employee details are recorded digitally.
3. Departments are created and managed.
4. Employees are assigned to departments.
5. Payroll is generated automatically.
6. Deductions and net salary are calculated.
7. Payroll reports are generated.
8. Management reviews payroll information.

## ⚙️ Installation

```bash
# Clone repository
git clone https://github.com/your-username/epms.git

# Install backend dependencies
cd backend
npm install

# Start backend server
npm run dev

# Install frontend dependencies
cd frontend
npm install

# Start frontend application
npm start
```
